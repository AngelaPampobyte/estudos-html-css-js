# Programação para Internet - Estudos Web

Repositório com atividades práticas de HTML, CSS e JavaScript desenvolvidas durante meus estudos.

## Contexto

Atividades da disciplina de Programação para Internet, do curso de Gestão de TI - 4º semestre, Fatec Itaquaquecetuba.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (em desenvolvimento)

## Estrutura do repositório

| Pasta | Descrição |
|---|---|
| `01-primeira-pagina` | Primeira página HTML criada, usada para testar diferentes tags básicas. |
| `02-atividade-testes-comandos` | Página de apresentação pessoal, criada para testar diversas tags de HTML. |
| `03-atividade-cursos` | Página com lista de cursos da fatec, contendo links que redirecionam para páginas explicativas de cada curso (pasta `paginascursos`). |
| `imagens` | Imagens e recursos visuais utilizados nas atividades. |

## Como visualizar

Basta abrir o arquivo `index.html` de dentro de cada pasta diretamente no navegador.
